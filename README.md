


Лабораторная работа №2: In-memory база данных

Описание проекта
Данный проект представляет собой прототип базы данных, работающей полностью в оперативной памяти (in-memory). Реализованы две связанные таблицы: Авторы и Книги. Для каждой таблицы поддерживаются все основные операции CRUD (Create, Read, Update, Delete) с возможностью фильтрации записей по любому полю. Проект выполнен в рамках лабораторной работы по дисциплине «Программирование и основы алгоритмизации».

Назначение ключевых файлов:

__main__.py – запускает приложение (вызывает функцию run() из tui.py).

tui.py – содержит все функции взаимодействия с пользователем: меню, ввод данных, вывод таблиц, обработка исключений.

memory.py – реализует хранение данных в списках кортежей, функции для создания, чтения, обновления и удаления записей, а также проверки целостности (например, существование автора при добавлении книги).

Функциональность
Таблицы
Авторы (authors) – хранит информацию об авторах книг.

Поля: id (уникальный целочисленный идентификатор), name (имя), country (страна).

Книги (books) – хранит информацию о книгах.

Поля: id (уникальный целочисленный идентификатор), title (название), author_id (ссылка на автора), year (год издания), genre (жанр).

Операции
Для каждой таблицы реализованы:

Добавление записи – с проверкой уникальности id и (для книг) существования автора.

Поиск записей с фильтрацией – можно задать значения для любого поля (или оставить пустым, чтобы пропустить фильтр). Возвращается список записей, удовлетворяющих всем условиям.

Обновление записи – по id можно изменить любые поля (кроме самого id). При обновлении книги проверяется, что новый author_id (если задан) указывает на существующего автора.

Удаление записи – по id. При удалении автора проверяется, нет ли у него книг; если есть – удаление запрещается (сообщение об ошибке).

Обработка ошибок
Все операции защищены блоками try/except. При возникновении исключений (например, нарушение уникальности, неверный тип данных, отсутствие записи) пользователю выводится понятное сообщение, программа продолжает работу.

Интерфейс
Текстовое меню с выбором раздела (авторы / книги) и действий внутри раздела. Данные вводятся с клавиатуры, результаты выводятся в виде таблиц с выравниванием столбцов.

Инструкция по запуску
Убедитесь, что установлен Python 3.12 или выше (проект использует синтаксис type для псевдонимов, доступный с Python 3.12). Проверить версию можно командой:


python --version
Склонируйте репозиторий (если ещё не сделано) и перейдите в его корневую папку:


git clone <URL репозитория>
cd PIOA-...
Запустите программу как исполняемый модуль пакета:


python -m src.db
Примечание: команда выполняется из корня проекта (там, где находится папка src).

Навигация в программе – следуйте подсказкам меню. Для выбора пункта введите соответствующую цифру и нажмите Enter. При вводе фильтров пустое поле означает «пропустить условие».

Пример использования
Запускаем программу.

Выбираем «1. Работа с авторами».

Добавляем автора: ID=1, Имя=«Лев Толстой», Страна=«Россия».

Возвращаемся в главное меню, выбираем «2. Работа с книгами».

Добавляем книгу: ID=1, Название=«Война и мир», ID автора=1, Год=1869, Жанр=«роман».

Пытаемся удалить автора с ID=1 – получаем ошибку, так как у него есть книга.

Удаляем книгу, затем удаляем автора – успешно.
