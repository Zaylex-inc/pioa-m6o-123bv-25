


# Лабораторная работа №2: In-memory база данных

## Описание проекта
Данный проект представляет собой прототип базы данных, работающей полностью в оперативной памяти (in-memory). Реализована возможность создания произвольных таблиц с любым набором колонок (первая колонка обязательно `id`). Для каждой таблицы поддерживаются все основные CRUD-операции (Create, Read, Update, Delete) с возможностью фильтрации записей по любому полю. Проект выполнен в рамках лабораторной работы по дисциплине «Программирование и основы алгоритмизации».

## Назначение ключевых файлов
- **__main__.py** – запускает приложение (вызывает `run()` из класса `TUI`).
- **tui.py** – содержит класс `TUI` со всеми функциями взаимодействия с пользователем: меню, ввод данных, вывод таблиц, обработка исключений.
- **memory.py** – реализует два класса:
  - `Table` – хранит данные в списке словарей (`records`), выполняет проверку полей, реализует `insert_record`, `select_records`, `update_record`, `delete_record`.
  - `Database` – управляет коллекцией таблиц (`tables`), предоставляет методы `create_table`, `insert_record`, `select_records`, `update_record`, `delete_record`, `drop_table`.

## Функциональность

### Управление таблицами
- **Показать все таблицы** – отображает список всех таблиц с информацией о колонках и количестве записей.
- **Информация о таблице** – показывает детальную информацию о конкретной таблице (колонки, количество записей, пример записи).
- **Создать таблицу** – создаёт новую таблицу с заданными колонками (первая колонка обязательно `id`).
- **Удалить таблицу** – полностью удаляет таблицу со всеми данными (с подтверждением).

### Операции с данными
- **Вставить запись** – добавляет новую запись в таблицу. Для колонки `id` выполняется проверка уникальности и целочисленного типа.
- **Выбрать записи** – выполняет поиск записей с возможностью фильтрации по любому полю (можно указать несколько фильтров).
- **Обновить запись** – изменяет поля существующей записи по `id` (поле `id` изменить нельзя).
- **Удалить запись** – удаляет запись по `id` (с подтверждением).

### Обработка ошибок
Все операции защищены обработкой исключений. При возникновении ошибок пользователю выводится понятное сообщение:
- попытка создать таблицу без колонки `id`
- вставка записи с уже существующим `id`
- обращение к несуществующей таблице или записи
- ввод некорректных данных (например, текст вместо числа для `id`)
